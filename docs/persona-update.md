# 萤完整人设更新（2026-10-21）

本包使用桌面版已有的角色配置功能，无需重新下载完整运行环境。

1. 关闭萤 AI 对话，将本包内的 backend 文件夹复制到“萤AI对话.exe”所在目录并合并。
2. 打开桌面版，在设置的角色配置列表中选择“萤 · 完整人设（第20话之后）”。
3. 新建对话开始使用。旧对话已有的发言不会被改写。若重启后恢复默认配置，请再次选择此人设。

本包仅包含人设和原文，不覆盖 config/config.yaml，也不包含或替换 API 密钥、语音模型及 Live2D 素材。继续使用原来的日语配音、中文字幕与动作控制。
