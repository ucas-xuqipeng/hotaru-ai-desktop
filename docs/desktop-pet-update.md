# v1.1.0 桌宠模式与空闲鼠标注视

本次是给已有完整便携版使用的更新包，不包含 Python、Electron EXE、语音权重、Live2D 素材或私人配置，不能单独运行。

## 安装

1. 首次使用者先从 [v1.0.0](https://github.com/ucas-xuqipeng/hotaru-ai-desktop/releases/tag/v1.0.0) 下载完整分卷、合并并解压，配置自己的 AI API。
2. 需要完整人设时，另应用同一 Release 的 `Hotaru-Persona-20261021.zip`。
3. 下载 [Hotaru-Desktop-Pet-v1.1.0-update.zip](https://github.com/ucas-xuqipeng/hotaru-ai-desktop/releases/download/v1.1.0/Hotaru-Desktop-Pet-v1.1.0-update.zip)，解压到单独文件夹，先退出正在运行的萤。
4. 双击 `Apply-Update.cmd`，根据提示输入原完整便携版文件夹的路径。脚本会验证目录、备份原应用和前端，然后更新；不覆盖 API 配置、声音、Live2D、人设和聊天记录。
5. 启动原目录里的 `萤AI对话.exe`。首次进入桌宠模式；如果之前保存过完整窗口模式，可从托盘菜单切换。

也可以在 PowerShell 中明确指定原完整目录：

```powershell
.\Apply-Update.ps1 -Target 'D:\HotaruAI'
```

## 操作

- 人物独立透明显示并置顶；透明区域可点击穿透。
- 按住人物拖动位置，人物上滚轮缩放；双击人物或 `Ctrl+Alt+H` 开关输入面板。
- 空闲约 2.5 秒后，眼睛和头部平滑看向系统鼠标，鼠标在其他程序上也有效。输入框正在编辑、拖动、思考或说话时暂停注视。
- 右键人物或托盘图标，可开关麦克风、打断、隐藏、恢复位置、切回“完整窗口 / 设置”或退出。
- 选择完全穿透后，可用快捷键或托盘恢复交互。
- 原有中文输入、日语音色、中文字幕、表情、动作与口型继续使用。

固定透明窗口的原生样式避免 Windows 切换模式后不绘制的问题；完整窗口用来配置与查看聊天，桌宠大小通过滚轮或托盘调整。

## 备份与回退

备份保存在原完整目录下 `data/backups/pet-update-日期-时间`。退出萤后，在解压的更新包目录运行以下命令，替换为实际目录和备份名称：

```powershell
.\Rollback.ps1 -Target 'D:\HotaruAI' -BackupName 'pet-update-20261022-160000'
```

更新和回退仅复制应用与前端，不删除共享模型文件。
